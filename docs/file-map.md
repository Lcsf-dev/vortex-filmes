# Arquivos da Vortex Filmes

| Caminho | Conteúdo |
| --- | --- |
| `index.html` | Página de entrada e formulário |
| `home.html` | Catálogo, busca, destaques e detalhes |
| `css/` | Estilos compartilhados e de cada página |
| `js/login.js` | Validação do formulário |
| `js/home.js` | Busca, filtros, carrossel e reprodução |
| `js/movies.js` | Dados dos 96 filmes |
| `images/` | Marca, fundos e capas com nomes em português |
| `vendor/` | Bootstrap e sua licença |
| `docs/` | Documentos originais preservados |
| `archive/` | Imagens originais preservadas |

Os arquivos de código usam nomes em inglês; variáveis, funções e comentários próprios usam português. As capas usam títulos em português, sem acentos e separados por hífen.

O arquivo ZIP original foi removido após a extração. O histórico Git preserva a versão inicial.
